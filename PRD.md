# PRODUCT REQUIREMENTS DOCUMENT (PRD)

## Project Title

**Micro Budgeting for Small Businesses**

## 1. Problem Statement

Small business owners need to manage their money carefully. They may find it difficult to keep track of daily income, expenses, budgets, and remaining balance.

This application helps small business owners record their financial transactions and understand their business budget in a simple way.

## 2. Objective

The main objective of this project is to create a simple budgeting application that helps small businesses:

* Record income
* Record expenses
* Set a budget
* Track transactions
* Calculate the remaining balance
* View financial information easily

## 3. Target Users

The main users are:

* Small business owners
* Small shop owners
* Small-scale entrepreneurs
* Self-employed people

## 4. Main Features

### 4.1 Add Income

The user can enter:

* Amount
* Category
* Date
* Description

### 4.2 Add Expense

The user can enter:

* Amount
* Category
* Date
* Description

### 4.3 View Transactions

The user can view all recorded income and expenses.

### 4.4 Budget Management

The user can set a monthly budget and monitor how much of the budget has been used.

### 4.5 Balance Calculation

The system automatically calculates:

**Balance = Total Income − Total Expenses**

### 4.6 Dashboard

The dashboard displays:

* Total Income
* Total Expenses
* Remaining Balance
* Monthly Budget

## 5. Technology Used

**Frontend:**

* HTML
* CSS

**Backend:**

* Python
* Flask

**Database:**

* MySQL

## 6. Database

The application stores:

* Transaction ID
* Transaction Type
* Amount
* Category
* Date
* Description
* Budget information

## 7. Expected Outcome

The final application will provide a simple and easy way for small business owners to manage their daily income, expenses, and budget.

It will reduce the need for manual calculations and help users understand their financial position.

## 8. Future Enhancements

In the future, the application can include:

* Monthly financial reports
* Charts and graphs
* Export to Excel/PDF
* User login
* Expense alerts
* Profit and loss reports
